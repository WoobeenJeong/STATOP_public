# STATOP — 발표 스냅샷

STATistic Ontology Platform 의 세 가지 사용 흐름을 담은 정적 스냅샷입니다.
자료는 전부 **합성**이고, 각 페이지는 파일 하나로 완결됩니다 — 내려받아
더블클릭해도 똑같이 돕니다. 통계는 브라우저 안에서 그 자리에서 계산됩니다.
