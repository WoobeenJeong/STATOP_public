# STATOP 검정 검증 목록 (registry-tests) — 1.0.0

- 연계: `stat-validator-rfp-1.0.0.md` 모듈 A (A1 연산 선택 → A2 3색 후보 → A3 가정 plot → A5 재작성), `registry-errors.md` (검정별 오류·NaN 정책)
- 상태: 검토용 초안. 별도 지시 전까지 버전 증가 없이 덮어쓴다
- 목적: 질문 유형별로 **어떤 검정이 후보가 되고, 어떤 사전검사가 붙고, 어떤 조건에서 불가/가능/특히 적합인지**를 한 곳에서 관리
- ID 체계: `Q-` 질문 유형 / `T-` 검정 / `C-` 사전검사(가정) / `P-` 사후·보정·효과크기 / `R-` 3색 판정 규칙 / `S-T` 의미 타입 / `S-R` 연산 적합성 규칙 / `F-` 파생 함수
- 참고 구조: GraphPad Prism의 데이터표 유형(Column / Grouped / Contingency / XY / Survival / Multiple variables) 기반 분석 선택 흐름. Prism 세부 기능은 기억 기반이라 현행 버전 확인 필요

## 0. 항목 스키마 (추가 시 이 필드를 채운다)

| 필드 | 설명 |
|---|---|
| id | `T-xxx` 등 |
| name | 검정/검사 명 (영문 고정, 한글 병기) |
| question | 연결되는 `Q-` ID (복수 가능) |
| design | 그룹 수 / 대응 여부 / 척도 / 요인 수 |
| assumptions | 요구 가정 → 연결되는 `C-` ID |
| best_when | 특히 적합(초록) 조건 |
| blocked_when | 불가(회색) 조건 |
| caution | 조건부 가능(노랑) 사유 |
| alternatives | 대안 검정 ID |
| post | 기본 동반 사후/효과크기 `P-` ID |
| effect_size | 보고 기본 효과크기 |
| impl | 구현 라이브러리 (scipy / statsmodels / pingouin / 자체) |
| sources | 근거 (교과서·논문·내부 사례 #) |
| short_tag | 자동 이름용 태그 |

## 1. 질문 유형 (Q) — A1 선택지

| ID | 질문 유형 | 사용자 언어 예 | Prism 대응 |
|---|---|---|---|
| Q-01 | 차이 (그룹 간 위치 비교) | "A군과 B군이 다른가", "처리 전후" | Column |
| Q-02 | 비율/빈도 차이 | "양성 비율이 다른가" | Contingency |
| Q-03 | 연관 (두 변수 관계 강도) | "X가 크면 Y도 큰가" | XY (correlation) |
| Q-04 | 상호작용/조절 | "약효가 성별에 따라 다른가" | Grouped (two-way) |
| Q-05 | 경향/추세 (순서 있는 그룹, 시간) | "용량이 늘면 반응이 단조 증가하나" | (없음, 회귀로 우회) |
| Q-06 | 일치도/재현성 | "두 측정자가 같은 값을 내는가" | Column (Bland-Altman) |
| Q-07 | 분포 비교 (형태 자체) | "두 분포가 같은가" (위치 아님) | Column (KS) |
| Q-08 | 예측/설명 (회귀) | "Y를 X들로 설명" | XY / Multiple variables |
| Q-09 | 생존/사건 시간 | "생존 곡선이 다른가" | Survival |
| Q-10 | 조성 데이터 (bio 특화) | "motif 비율이 군 간 다른가" (합이 고정) | (없음) |
| Q-11 | 사전지정 대비 (Planned contrast) | "정상=교란≠암" | (없음, 사후검정으로 우회) |
| Q-12 | 표본 크기·대표성 (**분석 전 설계**) | "30만 행을 다 안 봐도 되나", "몇 개를 골라야 전체를 대표하나" | (없음) |

Q-10, Q-11은 Prism에 없고 내부 사례(#5, #7, #9)에서 나온 항목. 이 두 개가 이 도구의 차별점.

**Q-12 는 계열이 다르다.** Q-01~11 은 전부 "내 가설이 맞나"(검정)를 묻는다. Q-12 는 그
앞의 질문 — **"분석을 어떻게 설계하나"** 를 묻는다. 그래서 답이 p 값이 아니라 **n** 이다.

> 후보 **Q-13 재표집 안정성**("같은 절차를 다시 돌리면 같은 결론이 나오나")은 아직 방법 표가
> 없어 등록하지 않는다. 방법 없는 질문을 목록에 올리면 고를 수 있는 것처럼 보인다.

| T-1103 | 직교 대비 집합 | k−1개 대비 | 여러 사전 대비 | 다중검정 보정 불필요(직교) 또는 P-221 |
| T-1104 | 비모수 대비 (Mann–Whitney on pooled groups) | 비정규 | 정상+교란 vs 암 | 형태 유사 가정 |

> 사용자가 A1에서 "A = B ≠ C" 형태의 대비를 입력하면 T-121(omnibus) + 사후검정 대신 **T-1101을 초록**, T-121을 노랑("3군 다 다르다는 결론만 나옴")으로 표시한다. 이것이 #9의 구현.

### 2.12 Q-12 표본 크기·대표성

전체 N 행에서 n 행만 뽑았을 때, **뽑은 것이 전체와 얼마나 다른가**를 n 에 따라 그린다.
차이가 더 이상 줄지 않는 지점이 "이만큼이면 전체를 닮았다"는 n 이다.

| ID | 방법 | 거리 | best_when | blocked_when | 비고 |
|---|---|---|---|---|---|
| T-1201 | 부분표집 곡선 — **KS distance** (SC-DIST-18) | $\sup_t\lvert F_n(t)-F_N(t)\rvert$ | 연속 컬럼. 단위가 다른 여러 컬럼을 **한 축**에 놓아야 할 때 | 범주 컬럼 | 0~1 무단위라 컬럼 간 비교가 된다. 기본값 |
| T-1202 | 부분표집 곡선 — **총변동거리 TV** (SC-DIST-19) | $\tfrac12\sum_j\lvert p_{n,j}-p_{N,j}\rvert$ | 범주 컬럼 | 연속을 bin 없이 | KS 의 범주판. 같은 0~1 축에 놓인다 |
| T-1203 | 부분표집 곡선 — **1-Wasserstein 거리** (SC-DIST-13) | $\int\lvert F_n-F_N\rvert\,dt$ | 차이의 **크기**를 원 단위로 알아야 할 때 | 범주 | 단위가 원변수라 **컬럼끼리 더할 수 없다** |
| T-1204 | 고른 n 의 검증 — 뽑은 n 행 vs **남은 N−n 행** | T-701 (KS 검정) / T-201 (χ²) | n 을 정한 뒤 확인 | n 이 N 에 가까움 (남은 쪽이 너무 작음) | **전체와 대조하지 않는다** — 뽑은 것이 전체에 포함돼 있어 독립 비교가 아니다 |

> **T-1204 의 p 값을 결론으로 쓰지 않는다.** N 이 크면 아무 차이나 유의해진다 — 판단은
> 거리(효과 크기)로 하고, 검정은 "거리가 작은데도 체계적 차이가 있는가"를 보는 보조다.

> 곡선은 n 마다 **여러 번 다시 뽑아 평균**낸다. 한 번만 뽑으면 그 한 번의 운을 곡선으로
> 착각한다. 반복 횟수와 seed 는 기록되어 재현된다.

## 9. 의미 타입 · 연산 적합성 (M1)

### 9.1 의미 타입 (S-T) — 저장 타입과 별개

**[0,1] 값의 타입 판별 (DECISIONS)** — probability / proportion / normalized score /
expression index는 값 범위로 구분되지 않는다. 구분 축은 **무엇에 대해 정규화됐는가**다.

- **신호(가중치 순)**: 행 합·컬럼 간 관계 → min·max 정규화 흔적 → 분포 형태 → 분위수 구조 →
  음수·로그 흔적 → 소수점 정밀도 → (낮은 가중치, 보조) 컬럼명 패턴
- **제시**: 가능성 높은 순으로 **순위만** 표시하고 **점수는 보이지 않는다**(유사확률 표기 금지,
  의존 편향 방지). 동점은 공동 1위 → 다음 3위. 근거는 분포 형태를 말로 짧게(단봉형/쌍봉형/평탄).
- **신호 충돌**: 상충 신호가 있으면 순위를 낮추지 말고 **"상충"으로 표시하고 확정 요구**
  (예: 행 합=1 + `prob_*` + 쌍봉형 → 다중클래스 확률 vs 조성)
- **확정 요구**: 순위 차이뿐 아니라 **오분류 비용**도 본다. probability ↔ proportion처럼
  틀렸을 때 대가가 큰 조합은 차이가 벌어져도 확정을 요구한다
- 확정된 타입은 C-14(값 조건 검증)가 참조한다

| ID | 타입 | 추론 근거 (자동) | 함정 (노랑 → 사용자 확정) | 기본 허용 연산 |
|---|---|---|---|---|
| S-T01 | count | 비음 정수, 0 다수 가능, 상한 없음 | 0~1 정수만 있으면 이진 코드일 수 있음 | 합, 비율화, log(+eps), Poisson/NB |
| S-T02 | proportion (fraction [0,1]) | 실수, 0≤x≤1, **형제 컬럼 행 합≈1**(행 방향 정규화) | **0~1 값을 가진 count**(소수 비율로 저장된 카운트). probability·normalized score와 범위가 같아 구분 불가 → S-T14/15 대비 신호 확인  | CLR/ALR, logit, beta 회귀 |
| S-T03 | percent [0,100] | 0≤x≤100, 소수 1~2자리 | 정수로 저장된 percent ↔ count 혼동 | /100 → S-T02 |
| S-T04 | probability | [0,1], 행 합 대개 ≠1(행마다 독립 사건), 0/1 근처 집중(쌍봉형) 흔함. 컬럼명 패턴(prob, p_)은 **보조 신호** | proportion·normalized score와 동일 범위. **배타 클래스면 행 합=1이 되어 proportion과 진짜로 혼동** → 상충 표시 후 확정 요구  | p(1−p) 정규화 변동성, logit, Brier, 보정곡선·ECE |
| S-T05 | log-scale | 음수 포함, 컬럼명 log/ln/log2, 파생 수식에서 부여 | 원척도와 혼합 비교 금지 | 차이(=원척도 비율), 산술평균 |
| S-T06 | z-score | 평균≈0, SD≈1 | 표준화 기준 집단 불명 | 비교 시 기준 동일성 확인 |
| S-T07 | ordinal code | 소수의 정수 수준(≤10), 순서 의미 | nominal과 구분 불가 → 사용자 확정 필수 | 순위 검정, ordinal 회귀 |
| S-T08 | nominal code | 소수의 정수/문자 수준 | 순서 있는 것을 nominal로 오판 | 빈도 검정 |
| S-T09 | id | 고유값 비율 ≈ 1, 문자/정수 | 연속 변수로 오판 → 자동 hold 제안 | 분석 제외, 그룹 구조(C-05) |
| S-T10 | datetime | 파싱 가능 | — | 시간 누수(L2.1), 추세 |
| S-T11 | continuous | 그 외 실수 | 상한·하한 있는 물리량(예: 0 이상)은 변환 고려 | 전부 |
| S-T12 | clr / alr (파생) | M1-3 수정 버튼 또는 F-11/12로 생성 | 원 조성 세트가 로그에 기록됨 | 상관, 차이 검정 |

| S-T14 | normalized score | [0,1]이며 **컬럼 min·max가 정확히 0·1**(min-max 흔적) 또는 분위수 균등 간격(분위 정규화). 행 합 ≠1 | probability·proportion과 동일 범위. **원척도가 소실**돼 배치·집단 간 직접 비교 불가 | 순위 기반 비교, 동일 정규화 기준 내에서만 비교 |

### 9.2 연산 적합성 규칙 (S-R) — 두 컬럼(세트) 지정 시 즉시 판정

색: **빨강**=실행 가능하나 결과에 경고 잔존 + 원클릭 수정 제공 / 노랑=주의 문구 / 회색(Gate)=실행 차단.

| ID | 조합 (A × B, 연산) | 판정 | 왜 검증이 안 되는가 (배너 문구) | 원클릭 수정 | 근거 |
|---|---|---|---|---|---|
| S-R01 | fraction × fraction, 상관 (같은 조성 세트) | 빨강 | 조성 성분은 합이 고정되어 한쪽이 커지면 다른 쪽이 작아짐. 상관에 음의 편향(spurious correlation) 발생 | 세트 CLR 생성(F-11) → 지정 교체. 2성분이면 ALR(F-12) | Pearson 1897, Aitchison, Gloor 2017 |
| S-R02 | fraction × fraction, 차이/평균 비교 (군 간) | 빨강 | 원척도 비율의 차이는 척도 의존적·비대칭(0.01→0.02와 0.50→0.51이 동일 취급) | CLR 또는 logit 변환 | Gloor 2017 |
| S-R03 | count × count, 상관/비교, 총합(depth) 상이 | 빨강 | 총합 차이가 값을 지배함. 깊이 정규화 없으면 총합을 비교하는 것 | 비율화 후 S-R01 경로, 또는 NB 모형(T-803) | Whalen 2022 P3 |
| S-R04 | count 단독, log 변환 요청 | 노랑 | 0이 있으면 log 불가. **eps 를 일반 법칙처럼 제시하지 않는다** — 더하는 값에 따라 결과가 달라지고, 검출 한계 아래 값이 상수로 눌린다 | 0에서 매끄럽게 정의되는 변환을 먼저 본다 (VST·arcsinh). eps 를 쓴다면 그 값을 기록하고 결과가 그 선택에 얼마나 민감한지 함께 본다 | 내부 정의 — log(0) 미정의 · Feng et al. 2014, Log-transformation and its implications for data analysis (검출 한계 문제) · 내부 사례 #2 |
| S-R05 | probability, "변동이 크다" 질문 | 노랑 → Diagnostic | SD는 0.5 부근과 0/1 부근을 동일 취급. CV는 0 근처 과대 | SD + p(1−p) 정규화 + 2σ 병기(P-233) | 내부 #3 |
| S-R06 | log-scale × 원척도, 차이/상관 | 빨강 | log 척도에서의 차이는 원척도의 절대차가 아니라 **비율 변화**에 대응한다. log 값과 원척도 값을 섞어 차이·상관을 구하면 **동일한 척도에서의 비교가 아니다** | 한쪽 변환 통일 | 내부 사례 #2 (11절 매핑) · Feng et al. 2014 |
| S-R07 | percent × fraction | 빨강 | 100배 척도 불일치 | /100 통일 | 내부 정의 — 단위 환산 |
| S-R08 | ordinal code, 평균/ t-test | 노랑 | 코드 간 간격이 등간이라는 근거 없음. 연속형으로 다루려면 **동일 간격 가정을 먼저 확인**해야 한다 | 동일 간격 가정을 확인하도록 유도. 미충족이면 **순위 기반·ordinal 지표를 우선 검토**(T-103/123, ordinal 회귀 T-804, 분류로 처리 등) | Stevens 1946 척도론 · Velleman & Wilkinson 1993 (기계적 적용에 대한 반론) |
| S-R09 | nominal code, 상관/회귀 연속 처리 | 회색 | nominal 은 **범주 식별을 위한 코드에 불과**하고 순서 의미가 없다. 회귀 계수·상관계수를 그 값으로 해석하지 않는다 | indicator·dummy 로 변환해 사용 | 내부 정의 — 범주 식별 코드 · Stevens 1946 |
| S-R10 | id 컬럼이 분석 변수로 지정 | 회색 | ID 는 **관측값의 크기·순서와 무관**하며 단순히 관측치를 구분하기 위한 변수다 | hold 전환 | 내부 정의 — 식별자 |
| S-R11 | 집계값(합·평균) vs 원자료, 층화 변수 존재 | 노랑 | 합산이 층화 변수(size 등)를 지워 Simpson 역전 가능 | P(Y)와 P(Y\|Z) 병기(T-1006) | Pearl 2014, 내부 #5 |
| S-R12 | z-score × z-score, 기준 집단 상이 | 노랑 | z-score 는 **기준 집단의 평균·표준편차**로 산출된다. 서로 다른 기준으로 표준화된 값을 견주면 두 분포 자체의 차이가 섞인다 — 다만 그렇게 볼 **의도가 있을 수 있으므로** 막지 않는다 | 두 분포에 차이가 없는지 함께 제시하고, 동일 기준 표준점수로 다시 본다. 그 비교는 **간접 비교 수준**이라 직접 비교보다 떨어지고 부정확할 수 있음을 고지 | 내부 정의 — z 는 기준 집단 g 에 의존 |
| S-R13 | datetime 파생 피처 × 라벨, 시간 순서 무시 | 빨강 | 미래 정보 혼입(L2.1) | 시간 split 제안 (모델 목록) | Kapoor 2023 L2.1 |
| S-R14 | 미확정 의미 타입 포함 | 노랑 | 타입 미확정. 판정 보류 | 확정 드롭다운 포커스 | 내부 절차 — (선택 → 타입 확정 → 판정) |

- 수식 파서는 위 함수만 허용(화이트리스트). 임의 코드 실행 불가.

  더하는 값에 따라 결과가 달라지고 검출 한계 아래 값이 상수로 눌리므로, 일반 법칙처럼
  제시하지 않는다.
- 모든 파생 컬럼은 `{name} = {formula}; eps={eps}; created={ts}` 형태로 조작 로그(M0-8)에 기록되며 출력 md에 그대로 나온다.

## 8. 관리 규칙

- 새 검정 추가: 2절에 행 추가 + 필요한 C·P 연결 + 해당되면 R 규칙 추가.
- 새 의미 타입/연산 규칙/파생 함수: 9·10절에 행 추가. S-R은 반드시 "왜 안 되는가" 문구와 원클릭 수정 대상 F-ID를 채운다. 근거(sources) 없는 항목은 `비고: 내부 경험`으로 표시
- 판정 조건 변경(R): 임계값은 이 파일에만 두고 코드는 이 파일을 읽는다 (규칙 DB YAML의 원본)
- 내부 사례가 늘면 6절에 행 추가 후 대응 항목이 없으면 신규 ID 발급
- 이 문서는 별도 지시 전까지 덮어쓰기. 큰 구조 변경 시에만 버전 증가
