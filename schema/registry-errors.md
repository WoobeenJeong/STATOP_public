## 1. NaN 정책 (전 검정 공통)

### 1.1 도구 정책
- **결측 현황 표시**: 가져온 컬럼마다 결측 개수·비율, 행 기준 결측 패턴(어떤 컬럼 조합이 함께 비는지)을 표시. 결측이 라벨·그룹과 연관되면(C-13) red.
- **직접 실행하는 기능은 두 가지만**
  1. **NA 제거**: 사용자가 지정한 컬럼 기준 행 제거 / 컬럼 제거. 결측률 임계값(기본 30%) 초과 컬럼은 노랑으로 제거 제안.
  2. **경량 대치(선택)**: 표준 Python 라이브러리로 즉시 끝나는 방법만. 아래 1.1a 허용 목록.
- **그 외 방법은 "대안 목록"으로 안내만** — 어떤 방법이 이 데이터에 가능한지·무엇을 가정하는지를 표로 보여주고 실행은 하지 않음(1.1b).
- 제거·대치는 항상 **로그 기록 + 전/후 n 병기**. 대치된 셀은 세션 내에서 표시(음영)되고 출력에 대치 방법·비율이 남음.
- **0 ≠ NaN.** 조성·카운트에서 0은 값이고 NaN은 결측. 인입 시 빈칸·"NA"·"."·−999 등 결측 표기를 통일. 0이 특정 군에 몰리면 "0으로 채워진 결측 의심" 노랑.

#### 1.1a 실행 허용 대치 (경량, 단일 라이브러리 로드로 즉시)
| 방법 | 구현 | 조건 | 기록 |
|---|---|---|---|
| 상수(0) | pandas | 카운트·조성에서 0의 의미가 명확할 때만. fraction/확률에는 노랑 | 값 |
| 평균 | pandas | 연속·정규 근사, 결측 <10%. 분산 축소 경고 | — |
| 중위수 | pandas | 연속·비정규·outlier | — |
| 최빈값 | pandas | 범주·코드 | — |
| 그룹별 평균/중위수 | pandas groupby | 그룹 컬럼 지정 시 | 그룹 컬럼 |
| KNN | sklearn KNNImputer | 연속, n ≤ 50k, 컬럼 ≤ 200 (초과 시 비활성) | k |
| MICE (반복 대치) | sklearn IterativeImputer (BayesianRidge 기본) 또는 `mice`류 단일 패키지 | 연속·MAR 가정, 컬럼 ≤ 100, 반복 ≤ 10. 시간 초과(기본 30초) 시 중단·경고 | seed, 반복 수, 추정기 |

> 원칙: 위 표에 없는 추정기(MLP·트리 앙상블·딥러닝·GAN 등 계산이 오래 걸리는 것)는 지원하지 않는다. IterativeImputer의 estimator도 BayesianRidge 고정.

#### 1.1b 안내만 하는 대안 목록 (실행 없음)
| 대안 | 가정/조건 | 이 데이터에서의 가능 여부 판정 근거 |
|---|---|---|
| 행 제거(listwise) | MCAR | C-13 결과, 제거 후 n |
| 검정별 최소 제거 (1.2 코드) | — | 선택 검정 |
| 다중 대치 + 풀링 (Rubin) | MAR | MICE 실행 후 사용자가 외부에서 풀링 |
| 모형 기반 (혼합모형·Cox가 결측 허용) | MAR | 검정 전환 제안 (ML 코드) |
| 결측 지시변수 추가 | 결측 자체가 정보일 때 | C-13 라벨 연관 시 제안 |
| 도메인 상수 (검출한계/2 등) | 측정 하한 결측 | 컬럼이 농도·강도 계열 |
| 민감도 분석 (여러 방법 결과 병기) | 결측 >10% | 결측률 |

### 1.2 검정별 NaN 허용 방식

| 코드 | 방식 | 의미 | 적용 검정 |
|---|---|---|---|
| **LW** | Listwise | 분석에 쓰이는 컬럼 중 하나라도 NaN인 행 제거 | 회귀(T-8xx), 다변량, 이원 ANOVA(T-401) |
| **GW** | Groupwise | 그 군의 값만 없으면 그 관측만 제거, 군별 n 달라도 됨 | 독립 2군·k군 검정(T-101~105, 121~124, 201~203) |
| **PW** | Pairwise | 두 변수 모두 있는 행만 사용(상관행렬은 쌍마다 n 다름) | 상관(T-301~305). 행렬 전체 비교 시 n 불일치 경고 |
| **PR** | Pair-required | 짝 중 하나라도 없으면 그 짝 제거 | 대응 검정(T-111~113, 211), Bland–Altman(T-602) |
| **CW** | Complete-within-subject | 피험자의 모든 조건이 있어야 함. 하나라도 없으면 피험자 전체 제거 | RM ANOVA(T-131), Friedman(T-132), Cochran Q(T-212) |
| **ML** | Model-based (허용) | MAR 가정 하에 결측 그대로 적합 (제거 불필요) | 혼합모형(T-133, 404), Cox(T-807, 검열은 결측 아님) |
| **NO** | 불허 | 셀/성분에 NaN이 있으면 계산 불가 | 분할표(T-201~203, 211, 212: 범주 결측은 행 제거로 귀결), 조성 세트(T-1001~1006: 성분 NaN은 행 제거 또는 세트 재정의) |

> UI: 검정 선택 시 해당 방식이 뱃지로 표시되고, 자동 제거될 행 수가 미리 나옴. CW·PR은 제거량이 클 수 있어 대안(ML 계열)을 함께 제시.
